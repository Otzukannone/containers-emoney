# containers

Tugas 3 Belajar Flutter Episode 3 Row Column

Lanjutkan MenuPage yang sudah dibuat saat praktikum.
Selesaikan baris ke-2 dan baris ke-3.
Gunakan widget dasar yang sudah dipelajari:
Column, Row, Container, Icon, Text, dan SizedBox.
Belum diperbolehkan membuat reusable widget/class MenuItem.
Setiap menu harus dapat diklik.
Setiap menu harus membuka halaman yang berbeda menggunakan Navigator.push().
Setiap halaman tujuan minimal memiliki AppBar dan nama halaman.
Gunakan icon dan warna yang sesuai dengan fungsi masing-masing menu
